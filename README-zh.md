# Rebuild Editable PPTX

简体中文 | [English](README.md)

一个用于 Codex 的技能，可将幻灯片截图或参考图片高保真重建为高度可编辑的 16:9 PowerPoint 文件。

该技能不会简单地把原截图铺在幻灯片背景上，而是使用独立的 PowerPoint 对象重建版面，包括文本框、形状、面板、表格、图标、照片和装饰元素。最终文件既能保留参考图的视觉层级，也便于后续修改。

## 主要特点

- 将幻灯片截图重建为可编辑的 `.pptx` 文件
- 标题、正文、指标、卡片和页脚均保留为原生文本对象
- 使用 PowerPoint 原生形状构建面板、图表结构和表格网格
- 将照片、人物、Logo、图标和插画拆分为可独立移动的图片对象
- 尽可能还原布局、间距、配色、字体、层级和品牌风格
- 原始图标不可用时，采用风格统一的开源图标库
- 交付前渲染并逐页检查成品
- 检查文本溢出、裁切、意外换行、错位和重叠
- 在演讲者备注中记录外部素材的来源

## 适用场景

适合以下需求：

- 根据截图或导出的幻灯片图片恢复可编辑演示文稿
- 原始 PowerPoint 文件丢失时重新制作幻灯片
- 将扁平化设计稿转换为可独立移动的对象
- 在保留原有视觉风格的基础上优化或美化页面
- 重建表格较多、卡片式或信息密集型幻灯片

## 使用条件

- [Codex](https://openai.com/codex/)
- Codex 的 **Presentations** 技能及其本地 PowerPoint 工具链
- 用户提供的幻灯片截图或参考图片

该工作流通过 JavaScript ES 模块使用 `@oai/artifact-tool`，不使用 `python-pptx`。

## 安装

将本目录克隆或复制到 Codex skills 目录：

```bash
git clone <repository-url> ~/.codex/skills/rebuild-editable-pptx
```

如果技能没有立即被识别，请重启 Codex。

## 使用方法

上传一张或多张幻灯片截图，并要求 Codex 使用该技能。例如：

```text
请使用 $rebuild-editable-pptx，把这些幻灯片截图重建为 16:9 的可编辑
PowerPoint，所有文字、卡片、图标、照片和表格单元格都要能够独立移动。
```

你还可以补充具体要求，例如优先保证视觉还原度、指定输出文件名、替换字体，或者标记无法准确识别的文字以便人工复核。

## 工作流程

1. 以原始分辨率检查每张参考图片。
2. 盘点页面中的文字、形状、面板、图片、图标、表格和装饰元素。
3. 在 16:9 画布上使用 PowerPoint 原生对象重建页面。
4. 缺少原始素材时，从截图中裁出照片或插画并作为独立对象插入。
5. 为外部素材添加来源说明。
6. 导出并渲染全部幻灯片，执行溢出检查并修正视觉问题。
7. 交付最终的可编辑 `.pptx` 文件。

## 可编辑性标准

重建后的幻灯片不应将原截图作为整页背景。主要视觉元素必须能够独立选择和移动。复杂的位图内容可以保留为图片，但文字、容器、结构形状和表格单元格应尽可能使用 PowerPoint 原生对象实现。

## 项目结构

```text
rebuild-editable-pptx/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── implementation-recipes.md
```

- `SKILL.md` 定义核心重建流程和质量检查要求。
- `agents/openai.yaml` 提供技能的展示信息和默认提示词。
- `references/implementation-recipes.md` 包含可编辑对象、图片处理、图标准备、素材来源记录和质量检查的实现方式。

## 注意事项

- 输出质量取决于参考图片的分辨率和文字清晰度。
- 对无法辨认的文字应采用保守转录，不虚构事实、姓名、指标或其他信息。
- 精确匹配字体需要工作环境中已安装对应字体。
- Logo、复杂插画和照片可以保留为位图，但会作为独立对象插入，而不是与整页背景合并。
